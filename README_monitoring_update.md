# Обновление мониторинга v8

Что добавлено:

- GitHub Actions для планового запуска по понедельникам.
- Ручной запуск через вкладку Actions.
- Скрипт `tools/collect_updates.py`, который читает `data/sources.json` и обновляет `data/weekly_findings.json`.
- Кнопка в дашборде `Обновить данные`, она ведет на workflow в GitHub.

Как работает первый сбор:

1. Первый запуск делает первичный срез источников и сохраняет снимок ссылок в `data/link_snapshot.json`.
2. Следующие запуски сравнивают новые ссылки со снимком.
3. Новые события попадают в `data/weekly_findings.json`.
4. Дашборд читает этот файл и показывает находки.

Что скрипт уже пытается собирать:

- сайты;
- новостные блоки и блоги;
- публичные Telegram-каналы через web-версию.

Что пока не является стабильным автоматическим сбором:

- VK, потому что реакции и посты нормально собираются через API;
- Instagram;
- закрытые или динамические сайты.
