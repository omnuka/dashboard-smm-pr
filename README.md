# Serenity competitor radar

Дашборд для еженедельного мониторинга инфополя конкурентов Serenity.

## Что внутри

- `index.html` - страница дашборда
- `styles.css` - дизайн
- `app.js` - логика фильтров, таблиц и сводок
- `data/competitors.json` - база агентств из Brand Hub top100
- `data/sources.json` - источники мониторинга
- `data/service-summary.json` - сводка услуг по базе
- `data/weekly_findings.json` - текущие находки
- `data/weekly_findings.demo.json` - демо-данные

## Главная логика

Дашборд показывает не карточки агентств, а движение в инфополе:

- темы недели
- услуги, которые чаще всплывают
- лидеров по кейсам, SMM, СМИ и суммарной активности
- теги и хештеги
- бренды и клиентские компании, которые упоминают конкуренты
- последние находки по всем источникам

## Где менять данные

Основной файл для будущего мониторинга:

`data/weekly_findings.json`

Когда появится автоматический сбор, он будет обновлять именно этот файл.
