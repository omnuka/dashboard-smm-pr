# v17, СМИ и клиенты Serenity

Что изменено:

- Вкладка называется коротко: `СМИ`.
- В таблицах дата подписана как `Дата публикации`.
- Сборщик не должен подставлять дату сканирования вместо даты публикации.
- Добавлен фильтр мусорных находок: курсы валют, крипта, биржевые виджеты и технические блоки страниц.
- Добавлен файл `data/client_brands.json` с текущими клиентами Serenity для СМИ-мониторинга.
- Добавлен файл `data/media_sources.json` со стартовым списком медиа для нормального названия источников.
- СМИ-мониторинг теперь ищет не только упоминания агентств, но и текущих клиентов Serenity: ГК Красное Золото, Красное Золото, Русаков, Тунгутун, Авача, Виктория Бис, Укинский леман.
- Клиентские СМИ-находки помечаются `monitor_scope: client_brand`, чтобы не ломать рейтинг лидеров агентств.

Что загрузить в GitHub:

- `index.html`
- `app.js`
- `requirements.txt`
- `tools/collect_updates.py`
- `data/client_brands.json`
- `data/media_sources.json`
- `README_update_v17_media_clients.md`

После коммита запустить `Actions → Weekly competitor monitoring → Run workflow`.
