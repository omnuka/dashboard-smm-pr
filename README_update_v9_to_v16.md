# Dashboard SMM-PR, update v9-v16

Это единый архив со всеми правками с v9 по v16.

Что входит:

- убрана публичная кнопка обновления данных;
- убраны декоративные кружки у тем;
- сборщик стал точнее искать конкретные материалы, а не общие разделы;
- сайт больше не попадает во вкладку соцсетей;
- мониторинг строится по последним 7 дням;
- убраны колонки с бесполезными авто-рекомендациями;
- раздел «Тематики» переделан под типы материалов: кейсы, тренды, рейтинги, отчеты, анонсы, реклама и т.д.;
- лидеры рынка в верхних карточках стали кликабельными и ведут на сайты агентств.

Что загрузить в GitHub:

- index.html
- app.js
- styles.css
- requirements.txt
- tools/collect_updates.py

Папку data этим архивом не трогаем, чтобы не перетереть текущие данные мониторинга.
Папку assets тоже не трогаем.

После загрузки:

1. Commit changes.
2. Открыть Actions.
3. Запустить Weekly competitor monitoring вручную через Run workflow.
4. Дождаться зеленой галочки.
5. Открыть дашборд и нажать Ctrl + F5.
