# Обновление базы источников Serenity

Создано из `serenity_sources_combined.xlsx`.

Внутри:

- `data/competitors.json` - 118 агентств
- `data/sources.json` - 405 проверяемых источников
- `data/service-summary.json` - прежняя сводка услуг для фильтра
- `data/weekly_findings.json` - пока демо-находки, не живой мониторинг
- `data/source-manual-checks.json` - ячейки, где в Excel остались `проверить`, `не нашел`, `отсутствует`

Это обновляет базу источников для дашборда. Реальный сбор событий недели делается следующим шагом.
